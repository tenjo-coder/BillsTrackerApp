Billwise Portable

Run Billwise-Portable.exe. The app saves your bills and history in the BillwiseData folder beside this executable.

To move Billwise to another location or computer, close the app and copy the entire folder containing this README and executable. Include BillwiseData if it exists. Then run Billwise-Portable.exe from the copied folder.

On first launch, if BillwiseData does not exist, Billwise will try to copy existing data from %APPDATA%\Billwise.
